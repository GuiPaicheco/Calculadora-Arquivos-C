# Exercícios interativos de JavaScript

Página de exercícios com cálculo de média e jogo de pedra, papel e tesoura; conteúdo atual implementado em JavaScript.

**Contexto:** Estudo de lógica e DOM.  
**Tecnologias:** HTML, CSS e JavaScript.

## Visão do projeto

Apesar do nome histórico do repositório, a versão atual contém `exercicios.html`, implementado em JavaScript. A página inclui cálculo de média de notas e pedra, papel e tesoura.

## Executar localmente

Clone o repositório e sirva os arquivos localmente. Com Python instalado:

```bash
git clone https://github.com/GuiPaicheco/Calculadora-Arquivos-C.git
cd Calculadora-Arquivos-C
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000/exercicios.html](http://127.0.0.1:8000/exercicios.html). Preserve as pastas de imagens, estilos e scripts. Recursos externos, quando usados pela página, podem exigir conexão com a internet.
